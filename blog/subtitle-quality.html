制作影片对白字幕时，那些容易漏掉的小问题

Stephen Yang Kaiqi
25 Nov 2026

影片对白字幕的校对，除了文字内容，还包括标点体例、全半角、空格和双语结构的一致性。这些也是我年初在制作字幕小警察（Subtitle Inspector）时，根据实际工作需求设置的检查项目。本文以常见的中英双语字幕为例：中文在上、英文在下，各占一行；体例说明以实际制作场景为背景，具体项目仍以甲方爸爸的要求为准。下面按检查类别介绍一些具体问题。

字幕小警察目前已经发布 v0.1.0 版本，可在 GitHub 仓库页面查看安装包及对应说明。

一、排版与双语检查

1. 中文标点问题

在内地院线电影采用的字幕体例中，中文通常不包含标点符号；港澳台及海外发行版本、流媒体版本的标点要求有所不同，部分版本会保留逗号、问号等符号。Netflix 的简体中文指南明确规定不用逗号和句号，疑问句需要问号，必要时使用全角感叹号，并对引号另作规定。[1]

内地常见体例好 你明天来吗Okay, are you coming tomorrow?
香港常见体例好，你明天來嗎？Okay, are you coming tomorrow?

针对不同要求，在字幕小警察中可以调用或创建相应的检查预设。

2. 全半角标点问题

中英双语字幕需要分别遵循两种语言的标点规范。英文行中的逗号、句号、问号等标点符号应使用相应的半角字符；中文版本若保留标点，则按中文体例处理。

问题示例 · 英文混入全角标点等等 雨还没停Wait，it's still raining！
修改后 · 英文使用半角标点等等 雨还没停Wait, it's still raining!

“半角/全角标点混用”检查会根据行语言标记不一致的字符，便于统一处理。

3. 标点配对问题

引号应成对出现，前后样式也应一致。下面的开引号是弯双引号，闭引号却用了直双引号。

问题示例 · 前后引号不匹配他说 明天见He said, “See you tomorrow."
修改后 · 统一为成对弯双引号他说 明天见He said, “See you tomorrow.”

软件的“英文标点检查”会提示单、双引号缺失或样式不符，并跟踪跨字幕延续的引语；能够确定配对关系的闭引号可自动修正。中文引号「」、『』、书名号《》以及圆、方、花括号，则由独立的“括号/书名号配对”选项检查。缺失符号只作提示，补在哪里仍需对照原文。

4. 英文大小写问题

大小写也需按句子和项目体例核对。下例同时展示句首小写和缩写格式不统一：假设项目其他条目已统一采用大写的 P.M.，这一条也应保持一致。注：p.m. 本身也是有效写法。

问题示例 · 句首及缩写体例我们下午三点放映we screen at 3 p.m.
修改后 · 按项目体例统一我们下午三点放映We screen at 3 P.M.

“大小写检查”会提示独立句首小写、部分句中异常大写，以及同一份字幕里 A.M./a.m.、P.M./p.m. 的混用。单独采用其中一种写法不会因此报错，混用时则提醒按项目体例统一。

5. 空格问题

英文空格

英文需要检查词间和标点前后的空格，也要留意缩写内部被拆开的情况。

问题示例 · 缩写及标点间距她在做饭 等她一会儿She 's cooking.Wait for her !
修改后她在做饭 等她一会儿She's cooking. Wait for her!

这一例中，缩写内和感叹号前多了空格，句号后缺了空格。“英文空格”检查可定位部分标点间距和单词粘连问题；缩写或所有格内部的多余空格由“连续/多余空格”检查标记。

连续/多余空格

这项检查作用于中文行和英文行，包括连续空格、行首行尾空格，以及标点前不需要的空格。行首、行尾空格在部分渲染流程中会影响居中结果，连续空格则造成不一致的间距。

问题示例 · 中英文均有连续空格等等 我还没准备好Wait! I'm not ready yet.
修改后 · 保留单个分隔空格等等 我还没准备好Wait! I'm not ready yet.

中英文混排空格

中文与拉丁字母、数字之间是否插入空格，取决于项目选择，但同一项目内需要统一。

不插入空格检查ABS和2号传感器Check the ABS and sensor 2.
插入空格检查 ABS 和 2 号传感器Check the ABS and sensor 2.

6. 双语结构与重复文本

中英文字幕合并、替换或更新后，除了看文字，也要核对每条是否仍有对应的中英文行。

问题示例 · 英文行缺失喂（英文行缺失）
修改后 · 恢复双语结构喂Hey!

双语模式中的“行数检查”按语言分别统计字幕行数，提示缺行、多行等结构异常；双语不平衡则根据中英文文本长度比例，筛查可能存在的部分内容复制、内容缺失或混入其他条目等情况。如果中英文字幕分别保存在两个文件中，可以使用“合并双语字幕”，根据时间码容差匹配对应条目，并提示未匹配项，方便核对中英文字幕的时间码是否对应。合并后，中英文共用一组时间码。完成编辑后，可以使用“拆分双语字幕”将双语字幕重新拆分为两个独立文件。

“重复文本检查”用来查找一条字幕中的意外重复：

问题示例这版先保留这版先保留Keep this cut.
核对后这版先保留Keep this cut.

原片中有意的重复、口吃和强调应保留。对“待确认”等交付前必须处理的标记，或本项目需要集中复核的写法，可以使用特别指定检查，并分别设置全部、仅中文或仅英文的标注词。

二、文件与文字检查

排版之外，软件也检查 SRT 文件结构与时间码：非法或重复序号、字幕块缺少空行、正文缺失、时间字段越界、结束早于开始等。时长、字幕重叠和间隔按项目参数提示。

“字数上限与 CPS” 用于筛出文字过长、显示过密的条目。中文和英文可分别设置上限；CPS 使用应用自己的中英加权计数，作为筛查指标，不直接代替平台验收值。

中文高级检查包括“的、地、得”、“本地词典疑似错字”、“用词一致性”、“简繁混用”和“非 GB2312 字符提示”。其中，非 GB2312 只是兼容性复核线索，不等于错字或字体缺字。

三、检查之后怎样修订

先按交付版本选择检查预设，确认单语/双语模式、标点和空格方案，再按类别处理提示。点击问题卡片可以定位原文；确认无需改动的提示可忽略，明确的空格、标点问题可批量修复。

自动修复结果会在新标签页中打开。要确认这一轮具体改了什么，可以使用“字幕比对”查看两个版本的文字、增删和时间差异；最后再将导出文件放回剪辑软件或播放器复核。

四、PNG/XML 图片字幕输出

IMAX DMR 的物料交付要求，是我开发 SRT 转 PNG/XML 子程序的原因：[3]

XML 字幕交付必须符合 CineCanvas 2.0 INTEROP 标准格式

2D 电影中，接收 4K PNG XML 字幕文件

若画面中同时出现多种语言字幕（如中文和英文），两种语言需要包含在同一个 PNG 文件中

这类交付由字幕图片和配套 XML 组成。PNG 保存字幕的实际字形与排版，XML 引用图片并描述其显示区间及位置。配套子程序可以从文字字幕生成逐条透明背景 PNG 和 CineCanvas 格式 XML。中文与英文可分别设置字体、字号、字距、行距、描边和位置，并通过参考画面、安全框及遮幅检查版式。可按 2K/4K 的 Scope/Flat/Container 画布导出全画面 PNG，也可导出为字幕区域 PNG 并在 XML 中记录 X/Y 轴位置。
